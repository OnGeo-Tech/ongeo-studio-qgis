# OnGeo US Parcel Explorer

OnGeo US Parcel Explorer lets you find U.S. parcels and addresses directly in QGIS,
add selected parcel boundaries to the map, and display nationwide parcel
boundaries.

## Getting started

The plugin supports QGIS 3.22 and newer, including QGIS 4. An OnGeo account and
an internet connection are required. Install the plugin from its ZIP package
using the QGIS Plugin Manager, then sign in from the OnGeo toolbar.

Enter an address or parcel identifier to search. Select a result to add it to
the map. The parcel layer control displays parcel boundaries across the U.S.
Select the information icon for parcel details and a link to the full property
report. Sign out from the account control when you have finished.
